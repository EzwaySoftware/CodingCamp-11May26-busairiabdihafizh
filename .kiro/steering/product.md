# Product

**Visualisasi Pengeluaran & Anggaran** — a personal finance tracker web app built in Bahasa Indonesia.

Core features:
- Track income and expenses by category (Makanan, Transport, Hiburan)
- Display total balance (Saldo Total)
- Visualize spending by category via pie chart
- Dark / light mode toggle with persistent preference (localStorage)

Target users: Indonesian-speaking individuals managing personal budgets.
